# Abhinav Kolla Portfolio

## Publish with GitHub Pages

1. Create a new GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html` and `style.css` to the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Your portfolio will be available at:
   `https://YOURUSERNAME.github.io/`

## Before publishing
- Replace the placeholder GitHub and LinkedIn links in `index.html`.
- Add your real project GitHub links.
- Optionally add your resume PDF and a profile photo.
